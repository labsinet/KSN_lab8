# ЛР8: Ознайомлення з системою Vagrant

Шаблон репозиторію з автоматичною перевіркою (GitHub Actions).

## Як виконувати
1. Натисніть **Use this template → Create a new repository** (приватний репозиторій, дайте доступ викладачу).
2. Клонуйте репозиторій. Шлях до папки — **лише латиницею**.
3. Впишіть номер свого варіанту у `variant.txt` (одне число 1–29).
4. Заповніть `Vagrantfile`: box свого варіанту, hostname, ресурси (≥1024 МБ, ≥1 CPU), прокидання порту 80→8080, provisioner з вебсервером.
5. Виконайте всі команди з методичних вказівок (`up`, `ssh`, `status`, `halt`, `reload`, `provision`, `snapshot`, `box list`, `global-status`, `destroy`).
6. Заповніть `report.md` (виводи команд, пояснення, відповіді на 10 питань).
7. Додайте щонайменше **5 скріншотів** (`.png`/`.jpg`) у папку `screenshots/`.
8. `git add . && git commit -m "ЛР8" && git push` — і перегляньте результат у вкладці **Actions**.

## Що перевіряє автоматика (100 балів, прохідний — 70)
| Перевірка | Бали |
|---|---|
| Коректний `variant.txt` | 5 |
| Наявність `Vagrantfile` | 5 |
| `vagrant validate` без помилок | 10 |
| Box збігається з варіантом | 10 |
| Заданий `hostname` | 5 |
| ОЗУ ≥ 1024 МБ та `cpus` | 5 |
| Проброс порту 80 → 8080 | 5 |
| Provisioner встановлює вебсервер | 10 |
| ПІБ, група, варіант у звіті | 5 |
| Виводи версій `vagrant` та VirtualBox у звіті | 5 |
| Усі команди керування згадані у звіті | 5 |
| Скріншоти (≥5) | 10 |
| Відповіді на 10 питань (≥40 символів кожна) | 20 |

> Автоматика **не запускає ВМ** (на хмарних раннерах GitHub немає VirtualBox). Вона перевіряє конфігурацію та повноту звіту; достовірність виводів і скріншотів перевіряє викладач.

## Для викладача
- У налаштуваннях репозиторію ввімкніть **Settings → Template repository**.
- Таблиця варіантів знаходиться у `.github/scripts/check_lab8.py` (словник `VARIANTS`) — змініть, якщо оновлюєте список образів.
- Прохідний бал змінюється змінною `PASS_SCORE` у `.github/workflows/check.yml`.
